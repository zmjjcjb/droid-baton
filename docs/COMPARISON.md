# 与原版 dsh-baton 的对照

基线：dsh-baton 0.6.11，commit `27856b463a7344952da32263719acb6ae97f8bef`。本版 Droid Baton 0.2.1，2026-11-11。

## 对应能力

| 原版体验 | Droid Baton | 验证 |
| --- | --- | --- |
| Codex 保持主控，另一执行器干活 | MCP → 本地服务 → Factory Droid | MCP + 真实 Droid |
| 新建任务、返回 run/session ID | 对应 droid_send | 真实 Droid |
| 同会话续聊保留上下文 | Droid load_session | 真实 Droid |
| 运行中补充 | end_of_loop 投递到同一运行 | 真实补充改变最终文件 |
| 排队、编辑/移除队列 | followup，前序验收后执行下一条 | 真实排队 + 回归 |
| 查看输出、工具与用量 | 状态 API 与本地面板 | 真实输出 + 浏览器检查 |
| 等待完成/提问，避免模型轮询日志 | 事件 wait、wait-any、后台 CLI wait | MCP 并发 + 回归 |
| 提问转交、返回答案 | 原生 AskUser、自由文本、request_id 校验 | 真实 AskUser |
| 人工介入 | 面板补充、续聊、回答、取消，记录 human 来源 | 浏览器 + 回归 |
| 文件变化与真实检查结果 | 复用 Baton 证据引擎，检查与控制进程分离 | 真实失败→修复→通过 |
| 停止，不自行重试 | interrupt 后清理受管进程树 | 真实取消 + 后代进程回归 |
| MCP 断连可继续查结果 | 独立本地服务持有任务 | MCP 取消等待回归 |
| 重启后识别中断 | interrupted，不自动重放 | 重启回归 |
| 目录/会话列举、重命名、工具聚合 | 相应 droid_* 和 droid_call | 接口回归 |
| 本机私有通道 | owner-only socket + 带密钥 loopback 面板 | 权限/HTTP 测试 |

## 不如原版或语义不同

1. **原生窗口融合不足。**原版插件把任务直接放进 Harness GUI，也能识别原应用的人工插话。本版用独立面板或监视终端。Droid 会话是原生持久化会话，但不接管在其他客户端中执行的任务，不能声称与现有 Droid 窗口实时双向同步。
2. **Goal/后台追踪已增强，原生整合仍有限。**0.2 增加多轮目标监督、检查失败修复、停滞提醒、原生 Mission/worker 事件、Task 结果/持久化记录及受管后台 PID 跟踪，不再仅以本轮结束判定目标完成。但未实现完整 Mission Control 接管，也不保证发现未观察到的远程或外部任务。详见 [长期任务说明](LONG_TASKS.md)。
3. **安装与平台覆盖较少。**原版有 Harness 插件入口、可借宿主运行时免装 Node，有 macOS/Windows CI。本版需 Node 和 Droid，只完成 Linux 实测；不能承诺相同跨平台覆盖。
4. **更新较弱。**保留 stdio 热更新外壳，但 broker 需闲时停止重启；没有插件市场安装升级、宿主/插件版本同步机制。
5. **目录列表不是原生侧栏。**只列本桥登记目录。原生会话发现/读取依赖 Droid 保存格式，未来可能需要适配。
6. **steer 回执不同。**返回原 run_id，补充记在 steers 中，不另造一个与原任务同时结束的 run_id；实际仍送入同会话的下个工具循环。
7. **问答更基础。**没有原版替用户选项时的两次自检提示。权限只支持单次批准/拒绝，不实现永久授权、编辑 Spec、新会话交接等全部权限分支。
8. **不复现省额度数字。**验证了真实链路，没有大规模质量、速度或成本对照，不能承诺节省特定比例的 Codex 额度。已测量的是单次轮询的上下文体积（精简视图减少 92%），不等于整场会话的输入 token 同比例下降。
9. **验证积累较少。**覆盖核心路径和真实小任务；长期运行、超大仓库及跨平台异常恢复未全部验证。

## 额外取舍

- 默认阻止独立会话并发修改重叠目录，避免覆盖与证据混入；需要时显式放开。
- 独立检查使用可终止的受管进程组，避免检查阻塞控制接口。
- 不复制“所有检查通过就不要读代码”的提示，Codex 可按风险审查 diff。
- 不自动换模型或扩并发，沿用用户已有 Droid 配置。
- 监督者与执行者的职责分离靠工具描述约束，不是宿主级强制闸门：Codex 仍持有执行工具，重复读取只是不被鼓励。本地无法安装 dsh-orchestrator 那样的白名单闸门（Codex 与 Droid 是两个进程，没有统一的 `tools.definitions` 可拦截）。
